# Java 学习练习项目

这是一个简单的 Java 学习练习项目，包含一些基础语法和程序结构的示例代码。适合初学者了解基本数据类型、变量、运算符、输入输出等内容。

## 项目结构

- `Welcome.java`：一个简单的欢迎程序，展示了如何编写 Java 主类和输出语句。
- `TestInt.java`：整数类型练习，演示整数变量、赋值和输出。
- `TestFloatNumber.java`：浮点数练习，演示浮点类型和小数计算。
- `TestBoolean.java`：布尔类型练习，演示逻辑值和条件判断。
- `TestChar.java`：字符类型练习，演示字符变量和字符输出。
- `TestConstant.java`：常量练习，展示如何使用 `final` 定义不可变值。
- `TestOperator.java`：运算符练习，演示算术、关系和逻辑运算符。
- `TestVariable.java`：变量练习，展示变量声明、初始化和基本使用。
- `TestScanner.java`：Scanner 输入练习，演示如何从控制台读取用户输入。

## 编译与运行

在命令行中进入项目根目录后，使用以下命令编译并运行 Java 程序：

```bash
javac *.java
java Welcome
```

如果想运行其他程序，例如 `TestScanner`，则使用：

```bash
java TestScanner
```

## 说明

这个项目主要用于练习 Java 基础语法。如果你刚开始学习 Java，可以逐个阅读并运行这些示例，理解每个程序的作用和结构。欢迎继续添加更多练习代码。
